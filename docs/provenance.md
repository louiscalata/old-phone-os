# Provenance

OPOS has recorded contributions from muse-glimmer-30b, muse-spark-1.3, Muse Spark Open and muse-wonder-1.0, together with adopted Codex, Claude and Grok Bot work. This is a concise public snapshot summary, not an assertion that every line was generated by one model. Historical paid routes for muse-spark-1.3 and muse-wonder-1.0 are recorded in the private spend ledger. Included-allowance work does not reclassify earlier paid routes as free.

Detailed historical prompts and outputs are preserved in a private evidence ledger and have not been rewritten. Private task identifiers, output logs, spend timelines and original Git history are omitted from this public snapshot. Model-name metadata and provenance text alone do not establish served-weight identity or integration acceptance. Development credits and historical execution observations are the submitter's declarations; the original generation and execution receipts are not included in this snapshot.

## Validation scope

Accepted private-baseline checks and public-export checks are separate records. The private baseline had desktop UI and actual desktop Glimmer evidence, package-state validation, and an actual postmarketOS QEMU kiosk with a QA-only Pixman renderer after default GLES2/GBM failure. Native model inference and physical phone/modem behavior were not established by those checks.

Corrections to the public tree, including notices, packaging and request dispatch, need their own affected checks and canonical test discovery. Release manifests record the actual source archive, package and public snapshot identities once measured. No future public commit or archive hash is fabricated in this document.
