# Calls and messages through oFono

`src/opos/ofono_phone.py` can dial, hang up, and send a message through oFono. It does nothing unless `OPOS_CALLS=1`. The default is practice mode. The phone page still uses the simulated modem.

This is not switched on, and it has not been tried with a SIM. **NOT_RUN.**
